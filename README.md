# Frontend-Artifact
A modern, AI/developer-themed animated background built with pure JavaScript and HTML Canvas.

Instead of plain dots, it floats code symbols ({ }, </>, =>), tech words (AI, API, React, Vue, git) and small icons (arrows, nodes, cursor blocks), connected by faint neural-network lines. Particles react to the mouse, drift with a smooth sine-wave flow, and have depth for a 3D feel.

**Features**
- Zero dependencies, works with plain HTML, Vue or React
- Smooth 60/120 FPS motion (sprite caching and delta-time)
- Fully customizable colors, words, density and speed
- Pauses on hidden tabs and respects `prefers-reduced-motion`
